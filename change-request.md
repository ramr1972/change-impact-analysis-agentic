# Change Request: Rename totalPrice to totalGrossAmount in Checkout Type

## Summary
Rename the `totalPrice` field to `totalGrossAmount` in the `Checkout` GraphQL type in the Saleor core API.

## Details
- **Target type**: `Checkout` (GraphQL type)
- **Current field name**: `totalPrice`
- **New field name**: `totalGrossAmount`
- **Scope**: This is a breaking change to the GraphQL schema.
